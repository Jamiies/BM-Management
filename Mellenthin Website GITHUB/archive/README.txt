live. The real site is the HTML in the folder ABOVE this one.

pre-niche-2026-07-24/
-----------------------------------------------------------------------
The site as it stood immediately BEFORE Bill described his niche as
"mess management and investigating... understanding the source of
disconnect and then offering reorganization that leads to better results."

To view it:  open  archive/pre-niche-2026-07-24/index.html

WHAT ACTUALLY DIFFERS BETWEEN THE TWO

Everything below is the OLD version (this archive) vs the CURRENT version.
Anything not listed here is identical in both.

  The niche rewrite replaced the credibility framing with a process one.
  That read worse, so on 2026-08-10 the archive's STRUCTURE was restored
  while keeping the corrected positioning. The two are now closer than
  they were, and differ mainly in scope of language.

                new: same shape and same opening, but ties the range to the
                     actual work and notes engagements have a defined end.

                     Accounting Discipline / Hands-On Management, with the
                     star / check / dot icons. Restored from this archive.
                     The card body copy differs: the current one points at
                     forensic and court-facing work.

  services      old: 3 cards — Fractional CFO & Controller, Financial
  teaser             Reporting & Close, Budgeting & Forecasting
                new: 4 cards — the real service lines

SERVICES PAGE  (the biggest difference by far)
  old: EIGHT services, invented from his bio as a starting point —

THE ONE THING THAT IS NOT A FAITHFUL SNAPSHOT
-----------------------------------------------------------------------
The photo credit in this archive reads "Color-graded" (US spelling). At the
time this snapshot represents it actually read "Colour-graded" — a British
spelling that was fixed in the same working session as the niche rewrite.
That correction was carried into the archive deliberately, because it is a
typo fix and has nothing to do with what you are comparing. Everything else
is the genuine earlier version.

The stylesheet in this archive also includes a `.grid--4` rule that the old
pages never use. It is inert here and was left in so the two stylesheets stay
otherwise identical and easy to diff.


-----------------------------------------------------------------------
HOW THIS SNAPSHOT WAS MADE
-----------------------------------------------------------------------
This project is not under version control, so there was no commit to roll
back to. The archive was reconstructed by copying the current files and then
reversing each individual edit made during the niche rewrite. Every reversal
was verified to match exactly before being applied, and both versions were
then checked to confirm no language leaked between them.

WORTH FIXING: put this project under git. Then "go back and compare" is one
command instead of a reconstruction, and nothing depends on the edits still
being recoverable. See the docs folder.
